# Симулятор порванного туза Кости

Небольшая шуточная игра-кликер для iPhone на Swift и UIKit.

## Возможности
- Нажимай кнопку, чтобы постепенно повреждать карту туза.
- После 25 нажатий карта эффектно «рвётся».
- Счётчик порванных тузов и возможность начать заново.
- Интерфейс на русском языке.

## Совместимость
- Минимальная версия iOS: 15.0.
- Основная архитектура: arm64.
- Подходит для iPhone 6s с iOS 15.8.x.
- 32-битные устройства не поддерживаются этой современной сборкой.

## Сборка
Открой `SimulatorPorvanogoTuzaKosti.xcodeproj` в Xcode, выбери iPhone и нажми Product → Build.

GitHub Actions также собирает unsigned IPA. Для установки на устройство потребуется подписать приложение подходящим сертификатом или установить его способом, поддерживаемым твоим устройством.

## Сборка IPA через GitHub Actions
Открой вкладку Actions и запусти workflow **Build unsigned IPA**. Готовый IPA появится в Artifacts.
