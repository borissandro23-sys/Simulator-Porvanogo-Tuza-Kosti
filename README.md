# Симулятор порванного туза Кости

Шуточная iOS-игра-кликер на Swift и UIKit.

## Игровые возможности
- Нажимай на кнопку, чтобы наносить карте урон и получать монеты.
- Когда прочность карты заканчивается, туз разрывается и выдаёт награду.
- **Сила клика** — увеличивает урон от каждого нажатия.
- **Авто-надрыв** — автоматически повреждает карту каждую секунду.
- **Бонус за разрыв** — увеличивает награду за каждый порванный туз.
- Уровни, счётчик порванных тузов и достижения за 5, 10, 25, 50 и 100 тузов.
- Прогресс, монеты и улучшения сохраняются между запусками приложения.
- Интерфейс прокручивается и рассчитан в том числе на небольшой экран iPhone 6s.

## Совместимость
- Минимальная версия iOS: 15.0.
- Основная архитектура: arm64.
- Подходит для iPhone 6s с iOS 15.8.x.
- 32-битные устройства не поддерживаются этой сборкой.

## Сборка IPA
Открой вкладку **Actions** и запусти workflow **Build unsigned IPA**. После успешного выполнения скачай IPA из раздела Artifacts. Это unsigned IPA: для установки потребуется подходящий способ подписи или установки.

## Сборка в Xcode
Открой `SimulatorPorvanogoTuzaKosti.xcodeproj`, выбери iPhone Simulator или устройство и нажми **Product → Build**.
